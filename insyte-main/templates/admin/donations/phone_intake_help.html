Phone Donation Intake — Operator Playbook

Step-by-step reference for capturing donations over the phone.

Open intake console

Before you pick up

  • Open /admin/phone-intake/ and pick the campaign for this call.
  • Have the campaign's mandate-text card to hand for direct-debit calls.
  • Card calls require Stripe Elements to load — make sure the page is fully loaded before the donor reads digits.

1. Find the donor

The search box looks across the house file and the campaign data file at the same time. You can paste any of:

  • URN — the donor's reference number.
  • First or last name — partial matches work.
  • Postcode — spaces and case don't matter.
  • Phone number — any UK format (07700 900 123, +44 7700 900123, 0044…).
Result badges — house file means a confirmed donor, pending review means an auto-created record waiting for back-office to verify, data file means a donor sitting on a campaign import that hasn't been reconciled yet.

If the donor isn't there, click "Create new donor". The new record is saved as pending_review=True and shows up in QA for a back-office reviewer to confirm later. Don't re-create someone you can already see — flag the duplicate to ops instead.

2. Capture the donation

Pick the payment method first — the form changes to show only the fields that matter.

Card (MOTO)

  • Type the card holder name; the donor reads the rest into Stripe Elements directly. Never type the PAN, CVV or expiry yourself.
  • Hitting "Charge card" authorises the card now; the funds settle when QA approves the batch.
  • If the bank prompts SCA you'll see "awaiting authentication" — Stripe e-mails the donor a recovery link. Tell the donor to expect it.
  • Declined card → click "Retry charge" on the donation while the donor is still on the line. Two consecutive declines: log a non_financial donation and escalate to ops.

Direct debit

  • Sort code is two-three-three with auto-tab between groups. Account number is 6-8 digits — short numbers are left-padded for you.
  • Read the mandate paragraph that appears on screen verbatim. Tick the "I read this aloud" box only if you actually did.
  • Frequency is monthly, quarterly or annually. Start date defaults to the first of next month.
  • If the format check fails and you're certain the donor is reading it correctly, tick "Force save (BACS check skipped)". The donation is flagged for QA to verify.

Cheque pledge

Save the donation with cheque number and cheque date blank. Banking attaches it to a Paying-In Slip when the cheque arrives in the post.

Cash

Rare on phone. Same workflow as cheque. Confirm address so a receipt can be posted.

CAF voucher

Read back the voucher number to the donor before saving. CAF amount is whatever the voucher is worth, not whatever the donor wanted to give.

Postal order

Same flow as cheque pledge — number and date blank until banking sees the postal order.

3. Gift Aid

Tick Gift Aid only if the donor has confirmed, on this call, that they are a UK taxpayer and want to declare. If they're not sure, leave it off — they can always opt in later.

4. Daily batch

Every donation you take in a day rolls into one batch named Phone — your-username — YYYY-MM-DD — campaign-name. The right-hand panel shows running totals; if you switch campaigns mid-shift, a new batch opens automatically for that campaign.

Every phone donation enters QA as pending. Card auths held in requires_capture expire after 7 days, so QA must clear the batch the same week — auths within 24 hours of expiry trigger a notification to the QA team automatically.

Never

  • Type the donor's full PAN, CVV or expiry date into any field. Stripe Elements only.
  • Save bank details without ticking the verbatim-mandate checkbox.
  • Save a card donation without the donor present on the line — auth fails and the donation gets stuck.
  • Re-charge a failed card from the QA console. Operators retry while the donor is on the call; QA only captures or cancels.
