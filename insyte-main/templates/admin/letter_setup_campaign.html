Template syntax

Templates use docxtpl (Jinja2). Variables, conditions, and filters all work.

Substitution

{% templatetag openvariable %} donor_full_name {% templatetag closevariable %}

Condition

{% templatetag openblock %} if gift_aid == "Yes" {% templatetag closeblock %}
Thank you for Gift Aiding.
{% templatetag openblock %} endif {% templatetag closeblock %}

If / elif / else

{% templatetag openblock %} if amount_raw >= 500 {% templatetag closeblock %}major donor
{% templatetag openblock %} elif amount_raw >= 100 {% templatetag closeblock %}mid donor
{% templatetag openblock %} else {% templatetag closeblock %}regular donor
{% templatetag openblock %} endif {% templatetag closeblock %}

Filter

{% templatetag openvariable %} donation_date_obj|date_format("%d %B %Y") {% templatetag closevariable %}
{% templatetag openvariable %} amount_raw|currency {% templatetag closevariable %}

Available filters: date_format, currency, to_int, to_float.

For conditions that span multiple paragraphs in Word, use the paragraph tag {% templatetag openblock %}p ... {% templatetag closeblock %} instead of {% templatetag openblock %} ... {% templatetag closeblock %}.
