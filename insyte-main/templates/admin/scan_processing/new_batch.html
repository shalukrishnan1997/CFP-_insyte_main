Pending R2 Folders

Create scan batches from newly uploaded R2 folders. Each action creates a scan batch and starts processing.

The uploaded PDF filename becomes the batch name shown in QA. Name the PDF to match the physical batch slip, for example SlipBatch-9001.pdf becomes SlipBatch-9001.

Scanner setup (one-time) Expand
  1. Install rclone on the scanner PC.
  2. Configure it once with your R2 credentials: rclone config
  3. Create folders on the scanner PC: C:\ScanOutput\{client_code}\{appeal_code}\{payment_method}\
  4. Scan one physical batch per folder. When you create the batch in INSYTE, choose the matching document layout before OCR starts.
  5. Name the PDF file to match the physical batch slip before upload. INSYTE uses that filename as the scan batch and donation batch identifier.
  6. Schedule this command every 2 minutes via Windows Task Scheduler:
    rclone copy "C:\ScanOutput" r2:your-bucket/ScanOutput --min-age 30s
  7. Come back here — uploaded folders appear in the table below automatically.

Payment method folder names must exactly match: cheque, cash, card, direct_debit, caf, postal_order, non_financial
